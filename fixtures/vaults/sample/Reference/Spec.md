# Vault Conventions

How this vault is organised, so future me (and Diabase) can rely on it.

## Folders

- `Books/` — one note per book. Frontmatter: `title`, `author`, `rating` (1–5), `status`
  (`reading`, `finished`, `want`), `started`, `finished`, `genre`, `pages`, `tags`.
- `People/` — authors, with `aliases` for short names.
- `Daily/` — one note per day named `YYYY-MM-DD`, created from [[Templates/Daily]].
- `Projects/` — anything with an end state. Diabase has its own subfolder.
- `Archive/` — finished or abandoned things. Never deleted.
- `attachments/` — images and other binary files.

## Linking

Prefer wikilinks by note name (`[[Dune]]`). Use a folder prefix only when two notes share a name, as
with [[Projects/Ideas]] and [[Archive/Ideas]], or [[Work/Plan]] and [[Homework/Plan]].

## Ratings

Whole stars only. (I have broken this rule exactly once; see [[The Dispossessed]].)
