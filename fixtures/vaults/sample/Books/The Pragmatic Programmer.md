## Review

The 20th anniversary edition. Most of the advice is now so mainstream it reads like common sense (DRY,
tracer bullets, orthogonality, "don't live with broken windows"), which is exactly why it's worth reading
the original argument for each.

## Tips I actually adopted

1. Keep knowledge in plain text. (Hence this vault.)
2. Use tracer bullets: build a thin end-to-end slice before any layer is complete. That's how
   [[Diabase Roadmap#Phase 1]] is structured.
3. Fix broken windows immediately; they multiply.
